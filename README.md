# JoJo Royale — servidor en línea

Servidor WebSocket (Node 18+) de JoJo Royale: presencia de amigos, solicitudes,
retos, salas con código, batalla rápida y retransmisión de partidas.

- Instalar: `npm install`
- Arrancar: `npm start` (puerto `PORT`, por defecto 8080)

Pensado para Render.com (Web Service, plan gratis): build `npm install`, start `npm start`.
